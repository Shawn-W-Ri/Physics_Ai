<h2 id="physics-pde">01 · Physics & PDE</h2>
<p>重点不是只会解公式，而是理解“物理假设 → 控制方程 → 边界/初值条件 → 可计算模型”的链条。</p>
<ul>
<li>Heat / Diffusion equation</li>
<li>Wave equation</li>
<li>Poisson / Laplace equation</li>
<li>Advection–diffusion</li>
<li>Navier–Stokes 与流体问题</li>
<li>连续介质与守恒律</li>
</ul>

<h2 id="numerics">02 · Numerical Simulation</h2>
<ul>
<li>Finite Difference Method (FDM)</li>
<li>Finite Element Method (FEM)</li>
<li>Spectral Methods</li>
<li>ODE time integration</li>
<li>Stability / consistency / convergence</li>
<li>Mesh, discretization error and verification</li>
</ul>

<h2 id="ai-science">03 · AI for Science</h2>
<ul>
<li>Regression, Bayesian thinking, uncertainty</li>
<li>Classical machine learning for surrogate modeling</li>
<li>Deep neural networks for high-dimensional approximation</li>
<li>Physics-Informed Neural Networks (PINNs)</li>
<li>DeepONet / Fourier Neural Operator</li>
<li>Inverse problems and parameter estimation</li>
<li>Hybrid models: numerical solvers + learned components</li>
</ul>
